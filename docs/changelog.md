# 版本紀錄

## v2.0.0（2026-10-31）

v1 課程作品之後的延伸版本：從單一的氣泡排序動畫，擴充成十種排序演算法的互動式教學工具，並補上測試、CI 與設計文件。v1 的介面設計稿保留在 `ui-design/`，深色畫面、綠色代表完成、黃色代表比較、紅色代表交換的視覺語言也延續到 v2。

| 面向 | v1（第 4 組課程作品） | v2 |
|---|---|---|
| 演算法 | 氣泡排序 | 氣泡（主角）、雞尾酒、選擇、插入、希爾、合併、快速、堆積、計數、基數排序 |
| 輸入 | 先輸入個數（2–10），再逐格輸入 1–10 的整數 | 資料量 5–100 滑桿、五種初始排列、可重現的亂數種子；自訂 2–100 個 0–999 的整數，支援全形數字與多種分隔符號，錯誤訊息指出位置與原因 |
| 播放 | 按下後每 0.65 秒自動走一步，不能暫停或倒退 | 播放／暫停、上一步／下一步、回到開頭／跳到結果、時間軸拖曳、每秒 0.5–800 步 |
| 理解輔助 | 比較中的兩根長條變色 | 虛擬碼目前行標示、每一步的文字說明、圖例、指標與樞紐標籤、輔助陣列（暫存、計數、桶子）視覺化 |
| 統計與知識 | 無 | 比較、交換、寫入、額外空間、剩餘逆序對與排序進度；時間／空間複雜度與穩定、原地、自適應等性質；每個演算法的觀察重點 |
| 互動學習 | 無 | 預測模式（先猜會不會交換）、比較模式（多個演算法同一組資料、共同操作時鐘、名次與結果表）、分享連結 |
| 介面 | 英文、只有深色、固定版面 | 繁體中文／英文、淺色／深色、手機版、鍵盤快捷鍵、減少動態效果、色彩以外的符號提示、可選音效 |
| 程式結構 | `frontend/src/app.js` 一個檔案處理畫面與排序；`backend/bubblesort.js` 有另一份排序邏輯，但網頁沒有載入它 | 演算法（generator 送出事件）／引擎（重播、播放器、比較時鐘）／介面（控制器、元件、服務）三層；排序核心只有一份，前端以 ES 模組匯入 |
| 品質 | 只有 `node --check` 語法檢查 | 270 個 `node:test` 單元測試、軌跡驗證器、靜態路徑檢查、GitHub Actions（Node 20／22／24） |
| 文件 | README | README、需求規格、架構設計、測試計畫、版本紀錄 |

## v1.0.0（2026-05）

軟體工程課程第 4 組的繳交版本。

- 輸入要排序的數字個數（2 到 10 個），動態產生輸入框並檢查每個輸入值。
- 一步步顯示氣泡排序的比較與交換。
- 顯示排序結果，可以重新開始。
- 介面設計稿：`ui-design/`。
